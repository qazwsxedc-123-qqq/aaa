# 恶搞网页合集

8 个纯前端整蛊页面，双击 `index.html` 打开即可，不联网、不装任何东西、不读写本地文件。

## 怎么用

1. 双击 `index.html`，从首页点任意卡片。
2. 想发给人整蛊：把整个文件夹打包发过去，让对方解压后打开 `index.html`。
   微信/QQ 直接发 `.html` 文件对方可能收到的是 preview，建议压成 zip。
3. 想局域网共享：在文件夹里开个命令行，跑
   `python -m http.server 8000`，然后手机访问 `http://电脑IP:8000`。

## 怎么退出

- 任何页面按 **Esc** 回首页。
- 蓝屏/碎屏等全屏页面，第一次 Esc 可能只是退出全屏，再按一次即可。
- 实在不行直接关标签页。
